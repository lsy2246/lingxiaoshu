# AI全栈工程师 · 24小时实操面试

本题要求交付可运行功能，不能仅交方案、截图或AI生成的补丁。预计实际投入4–8小时；从双方确认的北京时间T0起，24小时内提交。

## 5分钟启动

环境：Node.js >=22.19.0（使用内置SQLite，可能显示实验性提示），pnpm 11.19.0。无需Docker、数据库安装、云账号或API Key。

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm run typecheck
pnpm run dev
```

浏览器打开 http://127.0.0.1:4317 。关闭服务用Ctrl+C；重置样例前先关闭服务，再运行 `pnpm reset`。首次启动自动创建 `data/interview.sqlite`，不要提交data目录。可通过PORT修改端口、INTERVIEW_DB_PATH指定独立测试数据库、INTERVIEW_TENANT设为tenant-a或tenant-b模拟服务端会话。不得把生产凭据放进项目。

先看docs/文件地图.md、docs/API与数据.md，再按docs/任务与验收.md复现。基础测试通过不代表题目完成，它只验证启动、保存和执行基础设施。须添加自己的修复回归及页面联调证据。

## 本题交付边界

实现任务卡状态→生产详情→编辑保存→可播放媒体→历史版本的一条完整链路。src、public为可运行的精简实现，保留少量真实辅助模块；reference内为双方确认的原项目文件参考摘录，不参与构建，不需要自行修补全项目依赖。完整React/Ant Design页面与庞大业务路由不能直接独立运行，已由本题轻量页面和窄接口承接边界。允许改用React等技术，但不要求换框架。

外部视频生成由受控执行器模拟；页面、接口、SQLite持久化及音视频播放必须真实工作。附带合成视频和合成音频，与口播文本并非TTS同步。没有真实供应商或原生产服务器。

已声明的考题缺口：状态投影、未绑定任务回退、读取组织/历史版本校验、页面异步竞态和错误反馈。不是在宣称原项目当前仍存在同样漏洞。
