# 文件地图与备注

| 文件 | 用途 | 候选人操作 |
|---|---|---|
| public/index.html、app.js、style.css | 真实浏览器页面、任务看板、工作台、媒体播放 | 完成状态、竞态、异常和操作闭环；可换框架 |
| src/server.ts、main.ts | HTTP接口、模拟服务端身份、静态文件、启动停止 | 修复读取授权和错误响应，保持写接口约束 |
| src/contracts.ts | 业务任务、运行、产物及内容数据契约 | 理解三个身份边界，必要时扩展 |
| src/store.ts | 真实SQLite事务持久化 | 可重构，保留重启恢复能力 |
| src/fixtures.ts | 两个组织、历史版本、阻塞任务、未派发任务 | 不可删掉问题数据以逃避验收 |
| src/executor.ts | 可控运行、缺授权、失败、成功结果 | 可扩展，不需要真实生成 |
| src/projection.ts | 状态投影，有明确缺口 | 修复映射 |
| src/production.ts | 内容读取与版本选择，有明确缺口 | 修复绑定、原产物版本与组织范围 |
| src/taskExecutionState.ts、taskMonitorView.ts、studioSocialTaskRead.ts | 真实项目辅助逻辑，已加中文解释 | 接入或用更合理实现替代 |
| public/media | 合成MP4/WAV，真实可解码 | 用来验证实际播放，非客户素材 |
| test/baseline.test.ts | 基础设施测试，含HTTP与持久化 | 添加自己的功能回归，勿只改断言 |
| reference | 确认范围内的17个原文件摘录及来源清单 | 阅读理解架构；不参与构建，import依赖未附全 |
| scripts/reset.ts | 停机后重置本题数据 | 仅本地测试使用 |

源代码注释解释职责与已声明的缺口，不提供完整修复答案。reference是参考材料，并非第二套可启动项目。没有包含整个原仓库、Git历史或业务台账。
